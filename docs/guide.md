## 快速开始

1. 在 Obsidian「设置 → 第三方插件 → 浏览」中搜索 Canvas Enhance，安装并启用。手动安装方法见 [README](../README.md#installation)。
2. 打开「设置 → Canvas Enhance → 基础设置 → 通用 → 界面语言」，选择中文。切换立即生效；“自动（跟随 Obsidian）”在中文环境使用中文，其他环境使用英语。
3. 创建一个项目画布，添加文本卡片作为主题。结束编辑后，选中卡片。
4. 按 `Tab` 添加下级节点；输入内容并结束编辑后，按 `Enter` 添加同级节点。
5. 将已有笔记拖入画布，点击文件卡片标题，在旁边的窗格阅读笔记。画布和笔记可同时查看。

下文设置路径均从「设置 → Canvas Enhance」开始。设置分为基础设置、思维导图、节点与边、进阶功能四页。只有标有重载提示的设置需要重载，界面语言无需重启。

## 重点功能

### 概览模式

缩小画布后，用大号标题快速识别卡片；放大后恢复原始内容。

1. 在「基础设置 → 概览模式」中启用功能。
2. 将画布缩小到阈值以下。文件卡片显示文件名或第一行标题；文本卡片显示第一个 Markdown 标题，没有标题时显示第一行文字。
3. 放大到阈值以上，恢复正常卡片视图。标题跟随节点颜色，分组标签也能保持可读。

| 设置 | 用途 | 默认值 |
|---|---|---|
| 触发缩放阈值 | 低于此值进入概览模式 | `0.4`（40%） |
| 文件节点标题来源 | 选择文件名或第一行标题 | 文件名 |
| 分组标签反向缩放 | 缩小时放大分组标签 | 开启 |
| 标题最大字号 | 限制大卡片上的标题字号 | `64` |

### 思维导图

在可编辑的画布中，选中一张卡片，并确保卡片编辑器和输入框都未聚焦：

| 默认快捷键 | 操作 |
|---|---|
| `Tab` | 创建下级节点 |
| `Enter` | 创建同级节点 |
| `Space` | 编辑选中的文本或 Markdown 文件卡片 |
| `Alt+方向键` | 在节点间导航 |

下级节点继承上级颜色，新节点按层级顺序放置。在「思维导图」页调整上下级水平间距、同级垂直间距、导航快捷键和颜色传播。

前三项快捷键可在 Obsidian「设置 → 快捷键」中修改。搜索“Canvas Enhance”及“创建下级节点”“创建同级节点”“编辑选中节点”。在卡片或普通 Markdown 编辑器内，空格、换行和正常输入不受这些操作替代。

若希望在卡片编辑中连续创建节点，可将创建下级、同级节点分别绑定为 `Shift+Tab`、`Shift+Enter`（也支持带 `Ctrl` / `Cmd` 的组合键）。它们仅在选中的文本或 Markdown 文件卡片编辑器内生效；创建后保留原内容，并进入新节点编辑。裸按 `Tab`、`Enter`、`Space` 仍用于正常输入，普通 Markdown 页面不受影响。同级节点需要已有父节点。

父节点上的加减按钮可折叠或展开下级分支，折叠状态随画布保存。它与后文的“可折叠分组”是两种操作。

### 文件模板 + 侧边栏打开

**文件模板**

用指定模板创建笔记卡片，将文件保存到指定文件夹。

1. 启用 Obsidian 核心“模板”插件，配置模板文件夹。
2. 在「基础设置 → 文件模板」开启功能。
3. 设置“选择模板”和“新建文件所在文件夹”；文件夹留空时，使用当前画布所在文件夹。
4. 运行命令“Canvas Enhance: 创建模板笔记节点”。也可将「通用 → 双击创建的节点类型」设为“文件”，再双击画布空白处。

**在侧边窗格打开文件**

1. 在「基础设置」启用“文件卡片分屏打开”，该项默认开启。
2. 点击文件卡片标题，或右键选择“在侧边栏打开”。
3. 文件在画布旁边的窗格打开，可阅读和编辑，画布保持可见。

继续打开文件会在同一侧边窗格新增标签页；已打开的文件复用原标签页。若要直接在画布内编辑 Markdown 文件卡片，选中后按 `Space`。

### 整体重排 & 子节点折叠

结束编辑或拖动后，点击画布底部工具栏的“整体重排”，整理整张画布。

- 普通思维导图保持分支连续；多条分支汇入的共享卡片只放置一次，并在避免重叠的前提下对齐关联卡片。
- 可见文本卡片高度自适应内容；折叠隐藏、固定宽高比及环形结构中的卡片保留尺寸。
- 分组与内部卡片整体移动，保留内部位置、尺寸和折叠状态。嵌套、重叠分组及跨越组边界的卡片一起平移。
- 浮动连线按起点、终点识别层级，连接侧仍自动调整。
- 输入不变时重复重排不再漂移；可以一次撤销恢复原布局。

含传送门的画布暂不支持整体重排。插件会提示，并保留原布局。

### 节点与边样式

在「节点与边」启用“节点样式”和“边样式”，通过右键菜单设置外观。

| 对象 | 可调整内容 |
|---|---|
| 节点形状 | 终端、流程、判断、预定义流程、文档、数据库等流程图形状 |
| 节点边框 | 实线、虚线、点线、隐藏 |
| 文本对齐 | 左对齐、居中、右对齐 |
| 连线 | 实线、点线、短虚线、长虚线 |
| 箭头 | 8 种箭头样式，包括三角形、菱形、圆形及轮廓样式 |
| 连线路径 | 曲线、直线、直角折线、自动避障 |

“自动避障”让连线绕开中间节点，适合复杂流程图。设置中还可调整默认颜色、默认样式、边方向和路径圆角。

### 自定义 CSS 样式

用 CSS 片段扩展节点和边的样式选项。下面的 YAML 注释定义一个节点菜单：

```css
/* @canvas-enhance-node-style
key: validation-state
label: 验证状态
options:
  - label: 无状态
    value: null
    icon: circle-help
  - label: 已通过
    value: approved
    icon: circle-check
*/
```

1. 将定义和对应 CSS 规则放入一个 CSS 片段。完整可用内容见[示例 CSS 文件](../assets/docs/example-custom-node-style.css)。仅有注释会添加选项，不会自动绘制状态标记。
2. 在 Obsidian「设置 → 外观 → CSS 代码片段」启用它。
3. 右键节点选择“验证状态”，应用样式。在「节点与边」还可配置自定义节点/边样式属性，并将自定义样式合并到一个下拉菜单。

![自定义样式属性菜单](../assets/docs/custom-style-attribute-example.png)

### 让画布接入知识网络

1. 在「进阶功能」启用“启用 .canvas 元数据缓存兼容”。如设置提示需要重载，先按提示重载。
2. 在文本卡片中加入指向已有笔记的 `[[双链]]`。
3. 打开关系图谱，以及目标笔记的反向链接和画布的出链视图，查看画布与笔记的关联。

画布可参与笔记间的链接网络。画布属性和单节点引用见后文。

![画布的元数据与链接集成](../assets/docs/metadata-cache-support.png)

## 其他功能

### 画布属性（Frontmatter）

为画布添加 `tags`、`aliases`、`cssclasses` 等自定义属性：

1. 启用前文的元数据缓存兼容，并启用 Obsidian 核心“属性视图”插件。
2. 打开画布，点击画布侧边工具栏的“属性”按钮。
3. 在属性视图中添加或修改属性。`cssclasses` 可配合自己的 CSS 片段设置画布外观。

### 单节点链接

在「进阶功能 → 启用 .canvas 元数据缓存兼容」下开启“启用 [[wikilink]] 引用节点”。选中节点，运行“复制节点 Wikilink”，或启用并使用节点弹出菜单中的复制按钮。

将复制的 `[[项目.canvas#节点ID]]` 粘贴到笔记，可引用单个节点；添加 `!` 成为 `![[项目.canvas#节点ID]]`，可嵌入该节点。

### 画布内搜索

画布处于活动状态时，macOS 按 `Cmd+F`，Windows/Linux 按 `Ctrl+F`。输入文字后跳转到匹配卡片；`Enter` / `Shift+Enter` 切换下一项 / 上一项，`Escape` 关闭搜索。

卡片编辑器处于活动状态时，快捷键使用编辑器原生搜索。在「基础设置」还可启用“类原生文件搜索”，让 Obsidian 的文件搜索检索画布内容。

![画布内搜索](../assets/docs/sample-search.gif)

### 图片导出

仅桌面端支持。在「基础设置」启用“图片导出”后：

1. 运行“导出画布为图片”；或先选中卡片，再运行“导出选中节点为图片”。
2. 选择 PNG / SVG，并选择“概览”显示标题，或“详细”显示卡片内容。
3. 选择主题及是否显示水印。PNG 可设置像素比和透明背景；SVG 可选择跳过字体导出。
4. 点击“保存”，选择导出位置。

### 自动调整节点大小

在「节点与边 → 自动调整节点大小」中配置默认启用、最大高度、垂直边距和网格对齐。文本或文件卡片会随内容调整高度，减少手动拖动。

![自动调整节点大小](../assets/docs/auto-node-resizing.gif)

### 图层顺序

在「节点与边」启用“图层顺序”。右键节点，选择置于顶层或底层；启用“显示上移/下移选项”后，可逐层调整遮挡关系。

![图层顺序菜单](../assets/docs/z-ordering-control.png)

### 可折叠分组

在「节点与边」启用“可折叠分组”。选中分组，运行“折叠/展开分组”，收起或恢复组内卡片。启用“拖拽时显示折叠分组预览”，可在拖动节点时看到折叠组边界。

![分组折叠前后](../assets/docs/collapsible-groups.png)

### 宽高比控制

在「节点与边」启用“宽高比控制”，右键节点选择“设置宽高比”。调整尺寸时保持比例，适合图片卡片。

### 浮动边

在「节点与边」启用“浮动边（自动选择连接侧）”。连接点可随节点位置自动选择合适的一侧，无需固定在上、下、左、右某一边；还支持未附着到节点的连接端点。

可进一步启用“允许创建浮动边”和“新边起点自动浮动”，调整新连线的默认行为。

![浮动边效果](../assets/docs/floating-edge-example.png)

### 翻转边

在「节点与边」启用“翻转边”，选中连线后使用弹出菜单中的翻转操作，将 A → B 变为 B → A。

![翻转边方向](../assets/docs/flip-edge.gif)

### 边高亮与选择

在「节点与边」启用“边高亮”，选中节点时突出其出边；可选“高亮入边”。启用“边选择”后，可从弹出菜单选择相连的边，也可按方向分别选择入边或出边。

![选中节点时高亮关联边](../assets/docs/select-connected-edges.gif)

### 自动文件节点连边

在「节点与边」启用“自动文件节点连边”，按设置中的 Frontmatter 键读取文件链接，自动关联画布中的文件卡片。保持默认键名可获得最佳兼容性。

### 传送门

在「进阶功能」启用“门户”。将另一个 `.canvas` 文件拖入当前画布，选中该文件卡片，在弹出菜单中选择“打开传送门”，即可嵌套查看另一张画布。

传送门与侧边窗格打开文件是不同功能。含传送门的画布暂不支持整体重排；传送门内部的连线操作也有限制。

![画布内嵌套另一张画布](../assets/docs/sample-portal-usage.png)

### 专注模式

在「进阶功能」启用“专注模式”，选中卡片后运行“切换专注模式”，让未选中的卡片模糊或暗化。再次运行命令可关闭。

![专注模式](../assets/docs/focus-mode.png)

### 封装选区

**此操作会移动节点，不是创建分组。** 想保留当前布局时，先在画布副本上尝试。

在「进阶功能」启用“画布封装”。选中节点，运行“封装选区”，输入新画布名称。节点及其内部连线移入新文件，原画布中出现一个链接到该文件的卡片。

### 增强只读

在「进阶功能 → 增强只读模式」配置隐藏背景网格、隐藏节点弹出菜单、禁用缩放和平移。切换画布到只读模式后使用这些限制，减少展示时的误操作。

### 扩展命令

在「基础设置」启用“扩展命令”。打开 Obsidian 命令面板，搜索“Canvas Enhance”。插件提供 20 多个命令；是否出现及能否执行，取决于功能开关、当前视图和选中对象。

| 目标 | 命令示例 |
|---|---|
| 添加内容 | 创建文本节点、创建文件节点、创建模板笔记节点 |
| 整理节点 | 克隆节点（方向）、扩展节点（方向）、交换节点、组合选中节点 |
| 浏览画布 | 导航（方向）、缩放到选中区域、缩放以适应画布 |
| 调整选区 | 水平/垂直翻转选中区域、选择所有边、选择入边/出边 |
| 引入笔记关系 | 拉取出链到画布、拉取反向链接到画布 |
| 其他操作 | 切换只读模式、切换专注模式、导出图片、封装选区 |

可以设置克隆间距、克隆后跳转及扩展节点步长。在 Obsidian「设置 → 快捷键」为常用命令配置快捷键。

## 设置参考

### 界面语言

在「基础设置 → 通用 → 界面语言」选择中文、English 或自动。设置、命令名称、画布控件，以及使用指南和更新日志入口立即切换；已打开的菜单或弹窗重新打开后显示新语言。旧版插件仍需重载。

### 节点默认值

「基础设置 → 通用」可调整双击创建的节点类型、新节点网格对齐、文本/文件节点默认尺寸、最小尺寸和最大宽度。选择“原生”双击类型时，保留 Obsidian 默认行为。

“禁用缩放时的字体缩放”控制分组标题和边标签的缩放行为；概览模式的分组标签另有自己的设置。

### 渲染与性能

“进阶功能”还有两个按需启用的选项：

- **节点渲染断点**：通过节点的 CSS 变量 `--variable-breakpoint` 指定缩放阈值，低于阈值时停止渲染内容，用于减少大画布的渲染负担。
- **替代文本渲染**：尝试统一编辑和阅读视图的渲染。它与 Obsidian 默认阅读视图存在视觉差异，启用后请检查自己的内容。


## 常见问题

**功能没有生效？** 先检查对应开关；只有设置提示需要重载时，才重载插件或 Obsidian。图片导出仅支持桌面端。未发布功能请对照更新日志确认版本。

**Tab、Enter、Space 没有执行预期操作？** 结束编辑，选中单张卡片，确认画布非只读，再检查 Obsidian 快捷键冲突。在编辑器和输入框中，这些键应保留正常输入行为。

**概览模式没有触发？** 默认阈值为 `0.4`，需缩小到 40% 以下。想更早显示标题，可调高阈值。

**文件模板列表为空？** 启用核心“模板”插件，设置模板文件夹，并确认文件夹内已有 Markdown 模板。

**文件替换了画布，没有在旁边打开？** 检查“文件卡片分屏打开”，并使用卡片标题或“在侧边栏打开”入口。

**如何反馈问题？** 在 [GitHub Issues](https://github.com/joeytoday/obsidian-canvas-enhance/issues) 附上 Obsidian 版本、插件版本、系统、复现步骤和不含隐私的示例画布。
